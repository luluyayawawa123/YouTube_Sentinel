## 更新内容

- 新增 Firefox 登录状态自动读取，支持选择实际使用的 Firefox 配置；无人登录 Windows 桌面时，SYSTEM 后台任务仍可读取已保存的配置，无需手动导出 Cookies。
- 诊断结果分别显示 YouTube 登录状态和 Firefox Cookies 读取状态，支持逐项实时进度、检测动画及不同颜色的结果标识。
- 修复部分视频因大量自动翻译字幕元数据导致检查失败的问题，精简视频详情输出，保留摘要需要的原始字幕和字段。
- 设置页统一记录与日志清理入口：按推送记录、执行日志、文本运行日志分类，支持清空全部或保留最近 7 天、1 个月、3 个月、1 年、3 年；结果逐类显示实际删除数量。
- 移除自动保留及自动删除，仅在用户手动确认后清理；保留监控目标、账号设置和视频去重记录。
- 新增博主自动获取并缓存头像，缺失缓存可自动补取，图片加载失败自动重试。
- 改善错误记录和界面提示，检查失败写入执行日志，避免冗长输出撑坏界面。
- 绿色版附带 yt-dlp `2026.10.26` 和 Deno `2.9.8`，无需另行安装运行时。

## 下载与使用

下载下方 Windows x64 绿色版 ZIP，解压后使用；无需下载安装器。SHA256 校验文件用于验证下载完整性。

首次使用：在固定目录解压，右键以管理员身份运行 `register-task.bat`，然后打开 `YouTube Sentinel.exe`，填写 AI 与 Telegram 设置，添加监控目标。

## 已部署用户升级

1. 关闭前台，并在任务计划程序中结束 `YouTube Sentinel Worker` 后台任务。
2. 将新版绿色包复制到原安装目录覆盖，**不要先删除旧目录**。保留服务器原有的 `config`、`data`、`logs` 内容，不要用其他电脑的个人配置或数据替换。
3. 打开新版前台，在任务计划程序中重新运行原任务。安装路径不变时，无需重新注册计划任务。
4. 在“设置与诊断”中选择已登录 YouTube 的 Firefox 配置，点击“运行诊断”确认，再手动巡检一次。

从 `v1.0.0` 升级请使用完整绿色包，确保补齐 Deno 并更新 yt-dlp；不要只替换 `app.asar`。

Firefox 会话失效或 YouTube 要求网页验证时，仍需在 Firefox 中完成登录或验证，后续请求会自动读取更新后的状态。
